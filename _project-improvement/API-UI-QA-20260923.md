# API 設定 UI 緊急修正版 QA — 2026-09-23

## 本次修正
1. 修正 API 設定視窗 DOM 巢狀錯誤：Gemini 分頁後多了一個 `</div>`，導致 Agnes / NVIDIA NIM / GroqCloud / OpenRouter / Mistral AI 的欄位被排到 modal 外面，造成黑底、低對比與無法正常操作的視覺問題。

3. 增加 API 設定按鈕與 API modal 的最終對比、hover、focus、active、pointer-events 鎖定，避免黑底黑字。
4. 保留 Google / Netlify Identity 測試模式關閉狀態。
