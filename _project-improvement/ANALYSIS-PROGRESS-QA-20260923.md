# 開始分析｜五階段進度與邏輯修正 QA

日期：2026-09-23

## 修正目標

「開始分析」不再用固定時間輪播或「經過時間／100 秒」計算假進度。百分比只在對應分析里程碑完成時前進。

## 五階段對應

| 階段 | 畫面文字 | 進度 | 觸發條件 |
|---|---|---:|---|
| 1 | 正在整理輸入資料與現況數據… | 8% | 開始分析後，完成輸入資料收集並建立 loading 狀態 |
| 2 | 正在比對產業基準，找出可能原因… | 24% | 輸入資料已完成，正式進入分析引擎／規則基準處理 |
| 3 | 正在模擬三種情境的預測數字… | 52% | AI 回應已完成結構化解析，預測資料可供整理；規則模式則完成對應本地計算 |
| 4 | 正在分析外部市場變因… | 76% | 外部變因、競品、SWOT 等環境資料完成整理 |
| 5 | 正在生成下一步行動建議… | 94% | 五層結果物件與建議資料已完成組裝 |
| 完成 | 分析完成 | 100% | 結果頁切換前的完成動畫結束 |

## API 模式

目前專案仍以一次完整 AI 請求產生五層分析，因此不能宣稱第三方模型在網路請求期間逐層回傳 5 個獨立結果。UI 階段改以「已完成的本地處理／AI 回應解析／資料正規化／最終結果組裝」作為真實里程碑，不再用時間假裝 API 內部進度。

## API 失敗時

若 AI API 失敗並切換規則模擬分析，進度仍依序經過第 3、4、5 階段，不會直接從第 2 階段跳到 99%。
